# React + Vite

Welcome to WTWR, What To WRRRRRR.

This apps api uses global positioning and time to track the weather in your current area. Based on the conditions WTWR suggests what articles of clothing ranging for shorts and sandles for the beach and hardshells for the snow.

WTWR, all weather is pictire weather.
